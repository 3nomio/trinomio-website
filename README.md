# Trinomio Institutional Website

Modern Next.js, React, TypeScript, and Tailwind project for the Trinomio institutional website.

## Commands

```bash
npm install
npm run dev
npm run build
npm run typecheck
```

## Structure

- `src/app`: Next.js app router pages, metadata, and global styles.
- `src/components`: Reusable interface sections and primitives.
- `src/lib`: Shared content and utility helpers.
- `public`: Static assets.
